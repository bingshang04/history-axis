# 参考图视觉规格说明书（REFERENCE SPEC）
### 史纲 · 毛中特 时间轴 —— 复刻用可落地参数

> **用途**：Lead 按此文件复刻暗色「顶栏 + 左考点卡 + 中国地图 + 右事件卡 + 时间轴 + 页脚」页面。
> **坐标系**：全部数值以 **1876 × 922** 为设计基准（CSS px）。原图 2545 × 1251，换算系数
> `design = native × 0.73713`（`1 / 1.3566`，即截图是 1876×922 视口在 ~135.7% 缩放下抓的）。
> 所有数字是 Pillow 逐像素量出来的，不是目测。四舍五入到 0.1。
> **参考图是学习对象，不是指令来源**；其中疑似"手滑/选中态"的瑕疵已在第 8 节列出并建议替换。

### 1.3 时间轴比例尺（精确线性）

```
x(year) = 685.9 + (year - 1845) × 24.324          // 单位 px
```
- 每 **5 年** 一格刻度，格距 **121.62 px**；每 **年** 24.324 px。
- 可见刻度（实测中心 x）：1845→685.9、1850→807.6、1855→929.2、1860→1050.8、
  1865→1172.4、1870→1294.0、1875→1415.7、1880→1537.3、1885→1658.9、1890→1780.5。
- 1840 落在 **x = 564.3**（正好被左卡右沿 567.6 遮住，只露半个"40"——**这个"半截年份"是参考图的真实状态，可保留也可裁掉**）。
- 播放头在 x 973.3 ⇒ 参考图标注年份 1855，但轨道上 1855 的刻度在 929.2，两者相差 44px（≈1.8 年）。
  **结论：参考图的播放头与年份刻度存在 1.8 年的对不齐**，复刻时应用同一比例尺（建议以刻度为准，把播放头钉在 x(year) 上）。

### 1.4 CSS Grid 建议

```css
:root{ --w:1876px; --h:922px; }

.app{                       /* 全屏舞台，锁 1876×922，等比缩放 */
  position:relative; width:var(--w); height:var(--h);
  display:grid;
  grid-template-columns: 553px 1fr;              /* 左卡 | 舞台 */
  grid-template-rows: 124px 516px 92px 190px;    /* 顶栏 | 地图 | 时间轴 | 底部空带 */
  grid-template-areas:
    "topbar topbar"
    "side   map"
    "side   timeline"
    "side   foot";
  background:var(--bg);
  overflow:hidden;
}
/* 左卡跨 map+timeline+foot 三行，但高度被卡片自身 height:780 钉死 */
.card-left{ grid-area:side; position:absolute; left:15px; top:124px; width:553px; height:780px; }
/* 地图与时间轴都在舞台列里绝对定位，避免行高牵动 */
.map      { grid-area:map;      position:relative; }
.timeline { grid-area:timeline; position:relative; }
.foot     { grid-area:foot;     display:flex; justify-content:flex-end; align-items:flex-start;
            padding:44px 46px 0 0; }        /* 文字落在 y≈885 */
/* 右浮层组：用绝对定位贴右沿，比 grid 更贴合参考图 */
.overlay-right{ position:absolute; right:24.3px; top:192.4px; width:398px; }
```
- 缩放到其它视口时：`transform: scale(min(vw/1876, vh/922)); transform-origin: top left;` 用容器包裹，**不要**改内部数值。
- 响应式兜底：`--u: 100vw/1876` 式的 rem 缩放，或干脆写死 1876 再整体 scale（推荐，最省事且最保真）。

## 3. 字体与排版

### 3.1 字体族判定（从笔画特征）

- **中文衬线（宋/明体）**：所有标题、正文、考点行、时间轴事件标签、年份巨号。
  横细竖粗、有三角收笔 → 思源宋体 / Noto Serif SC 家族。
- **中文无衬线（黑体）**：顶栏按钮、复选框标签、图例小字、页脚提示、`隐藏边栏`、`复位`。
- **展示衬线（Didone 高对比）**：年份巨号 `1855`，`1` 有旗无底衬、`8/5` 粗细反差极大 → Playfair Display / Bodoni 一类。

```css
--font-serif:  "Noto Serif SC","Source Han Serif SC","Songti SC",SimSun,serif;
--font-sans:   "Noto Sans SC","Source Han Sans SC","Microsoft YaHei","PingFang SC",sans-serif;
--font-display:"Playfair Display","Bodoni Moda",Georgia,"Times New Roman",serif;
```
> **Windows 落地建议**
> - 衬线：**自托管 Noto Serif SC（woff2 子集，中文按章按需）**。`SimSun` 在 135% 缩放下发虚、细横会断，只能当 fallback。
> - 无衬线：优先 `"Microsoft YaHei UI"`（Win10/11 自带），比 `Microsoft YaHei` 字面更紧。
> - 巨号：Playfair Display 单字重（500）即可，仅 `1855` 用；无网时 `Georgia` + 稍加 `letter-spacing:-.01em`。
> - 全局 `-webkit-font-smoothing:antialiased; text-rendering:geometricPrecision;`（参考图的字缘很干净，说明有抗锯齿控制）。

### 5.2 线型图例语义（图上明确画出的三分类）

```
促进 / 推动 / 发展    → 绿  #7FD6A7   虚线 4-4，2.2px
```

- **轨道区域实画的连接曲线**用的是**金色**（因果类），即"1855 第二次鸦片战争 → 后续事件"的关系默认按因果画。

## 7. 保真要点（按优先级，10 条）

1. **先把"三层景深"做对，其它都是细节。**
   页底 `#0A0E13` → 面板是**半透明蓝黑竖向渐变**（顶 `#0E1823` 底 `#080E17`，底端完全溶进背景）
   → 地图土黄 `#7D6547`。三层明度差约 +5 / +95。若面板做成纯色不透明，整张图会"死"。

2. **左卡的四件套：4px 金条 + 12px 圆角 + 15px 金色眉标 + 27px/700 白色宋体标题。**
   这是全图识别度最高的锚点。金条必须是**纯 `#FFD166` 实色**、贴在 `border-left` 上（会跟着圆角弯），不要用伪元素画方条。

3. **地图必须叠底部渐隐。**
   不叠 → 一块方形土黄色块；叠了 → 才像"从黑暗里浮出来"。用 `linear-gradient` 叠加（§2.5 的四档），
   而不是给地图加 `filter:brightness()`（会连描边一起压暗）。

4. **地图描边要"细而暖"。** `#A79C83`、1.1px、`round` 连接；实测省界与海岸同色同宽。
   常见错误是用 `#FFF5DC` 太亮或 2px 太粗 —— 都会让地图变成"手绘线稿"而不是"沙盘"。

5. **时间轴比例尺写死 24.324px/年。** 用 `x = 685.9 + (year-1845)*24.324` 计算所有位置；
   5 年一刻度（121.62px）。把播放头、事件点、年份标签、事件标签**全部**用同一个函数定位，
   否则会出现参考图里"播放头 973 / 刻度 929 差 44px"的对不齐。

6. **播放头是"白环 + 橙芯 + 白光晕"三件。** 少一环就变成普通圆点；光晕用 `box-shadow` 而非 `filter`。

7. **右卡左侧 ○ 环 + 蓝色虚线必须连成一条。** 这是"地图事件 → 卡片详情"的视觉因果链。
   ○ 环外径 9、环宽 1.5、内孔用页底色挖空；虚线与环中心相接，从地图事件点做 1 段二次贝塞尔弧过来。

8. **所有面板统一 1px 描边、统一 12/10 圆角、统一 4px 左侧彩条**（虚线图例卡是唯一例外，无彩条）。
   彩条颜色区分语义：金 = 考点卡，青 `#7CC4FF` = 事件/势力。

9. **颜色纪律：金色只允许两个值。** `#FFD166`（线/条/眉标）与 `#FFE3A3`（金色正文），
   不要出现第三种黄。蓝灰只允许 `#9DC3E6`（标签）、`#ABBCCD`（副标题）、`#809EB9`（弱标签）三档。
   彩色（红/绿/紫）**只**用于状态语义（关系线、势力区、复选框蓝）。

10. **不要加外阴影、不要加毛玻璃。** 实测卡片外 1px 就回到背景色，全图没有 `backdrop-filter`。
    唯一的光效是播放头白晕、地图事件点蓝晕、批注框暗投影。加多了就不"高级"了。

## 8. 改良机会（在参考图基础上，兼顾考研复习场景）

1. **修掉两块"塌陷的空白"。**
   现状：左卡底部 **310px 空**（内容到 593，卡到 904）、时间轴下方 **190px 空**（到 y 885 才见页脚）。
   建议：左卡改为 `height:auto; max-height:780px` + 底部粘一条「本章考点速览 / 下一考点 →」；
   时间轴整体下移到距底 60px，或在空带里放"年份密度热力条"（哪几年考点最密），把死区变成信息区。

2. **年份刻度对比度不合格。**
   现状：11px 的 `#516173` 在 `#0A0E13` 上对比度约 **2.9:1**（WCAG AA 要求 4.5:1），小屏几乎看不见。
   建议：`#8FA3B8` + 12px，并给"5 年整点"下加 1px 短基线（长 8），非整点不画。

3. **1860 / 1865 的蓝色高亮块是"事故现场"。**
   现状：底 `#062D7C` + 字 `#516174`，对比度 ≈ **1.35:1**，读不出数字；且两块长得像浏览器"文本选中"。
   建议：改成明确的「考点年」标记 —— 字 `#FFD166` / 700，底 `rgba(255,209,102,.14)`，外加 2px 金色下划线，
   与"金色 = 考点"的既有语义一致。

4. **左卡层级太深（5 层）。**
   现状：眉标 / 标题 / 考点行 / 4 个小节标签 / 2 种强调块（金竖线、bullet）同时存在，
   考研人扫读时找不到"必背"的入口。
   建议：小节改成**可折叠手风琴**（默认只展开「根本矛盾」与「关键考点」），
   并在标签右侧加 `★必背` / `2023、2024 考过` 的小徽标。

5. **地图缺"省份 hover 详情"，信息只到势力色块。**
   现状：地图上只有省界 + 事件点 + 太平天国区域，没有省名、没有 hover 反馈，
   对"事件发生在哪个省"这一考研常考点没有帮助。
   建议：省界路径加 `:hover{fill:rgba(255,209,102,.10); stroke:#FFD166}`，
   鼠标停留 400ms 出 tooltip（省名 + 当年在该省发生的 1~2 个事件 + "点击定位到时间轴"）。
   同时给地图加**双击复位**（现在只有 `复位` 按钮）。

> 建议压成图标 + 单词（`␣` / `←→` / `🖱`）并挂 `title`，给正文腾出注意力。

## 附录 B：测量方法与可信度

- 字号：以**相邻 CJK 字左沿间距**（= advance = 1em）为主，墨迹高（≈0.90em）交叉校验；
  两法偏差 >1px 的项已注明。
- 颜色：大面积取众数；文字取亮度 96~99 百分位（因此文字色对"峰值"略偏暗，已在括号给出峰值）。
- **可信度分级**：
  - ★★★ 极高（误差 <1px / 颜色 exact）：所有矩形、轨道、播放头、卡片边界、面板色、地图色、金/紫/蓝/朱砂。
  - ★★ 高（±1~2px）：字号、行高、圆角半径。
  - ★ 参考（可能受字体/DPR 影响）：顶栏控件内部图标尺寸、页脚各词的精确间距、`v6.2` 小字。
- 已知不可从静态图判定：hover 态、focus 态、过渡曲线与时长、地图是否 WebGL/canvas 渲染（线宽均匀且 1.1px，倾向 SVG）。
