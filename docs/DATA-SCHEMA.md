# 数据契约（DATA-SCHEMA）

所有数据文件为 **UTF-8（无 BOM）、LF 换行、纯 JavaScript**（非 JSON、非 ES Module）。
不使用 `import` / `export` / `require` / 模板字符串中的反引号嵌套；不写 Markdown 代码围栏。
每个文件通过 `<script>` 在 `index.html` 中按顺序加载，挂到 `window` 上。

加载顺序：

```
data/china-geo.js        → window.CHINA_GEO
data/shigang-periods.js  → window.SHIGANG_PERIODS
data/shigang-events.js   → window.SHIGANG_EVENTS
data/mao-data.js         → window.MAO_DATA
```

## 1. 地图 `window.CHINA_GEO`（由 `tools/build_geo.py` 生成，勿手改）

```js
window.CHINA_GEO = {
  width: 1000, height: 760,
  bounds: {                              // 均为 [x0, y0, x1, y1]（SVG 坐标）
    mainland: [18.0, 58.7, 982.0, 701.3], // 大陆 + 台湾 + 海南主岛
    scs: [561.6, 595.7, 789.4, 935.0],    // 十段线 bbox
    scsIslands: [580.8, 717.8, 711.9, 928.4]
  },
  provinces: [
    { id: "320000", name: "江苏省", short: "江苏", path: "M...Z", center: [x, y], label: [x, y], area: 123.4 }
  ],
  nineDash: { segments: [[x1, y1, x2, y2], ...] }, // 10 段，主图不画，只在右下角插图用
  project: function(lon, lat) { return [x, y]; }
};
```

- 投影为 **Miller 圆柱**（`tools/build_geo.py` 默认）；`bounds.mainland` 由纬度 ≥18° 的省界坐标计算，主图 viewBox 用 `[x0, y0, x1-x0, y1-y0]`。
- `center` 为省份几何中心的 SVG 坐标；`label` 为建议标注位置。
- `project(lon, lat)` 将经纬度转为与本图一致的 SVG 坐标，事件数据只存经纬度。
- 主图只显示 `bounds.mainland` 区域；南海诸岛/十段线放在右下角 96×126 插图，不参与主图平移缩放。

## 6. 质量要求

- 事实准确：会议届次、年份、文件名、条约名、人物、理论表述必须正确；不确定的细节宁缺毋滥。
- 考研口径：优先使用教材/大纲原表述，避免网络段子与戏说。
- 文案紧凑：左卡在 1855×~720 的可视区域内不出现大面积滚动（默认只显示所选事件的完整卡片，允许滚动）。
- 中文标点：全角标点；书名号《》；引号“”。

### `window.AXIS_DYNAMICS`

```js
window.AXIS_DYNAMICS = {
  routes: [
    { id: "long-march", name: "红军长征", from: axisYear(1934, 8), to: axisYear(1936, 10),
      color: "#b05846", points: [[lon, lat], …], note: "瑞金 → 遵义 → 吴起" }
  ],
  bases: [
    { id: "jinggangshan", name: "井冈山", from: axisYear(1927, 10), to: axisYear(1930, 2),
      lonlat: [lon, lat], r: 24, note: "…" }
  ]
};
```

- 所有时间用 `axisYear(year, month) = year + (month-1)/12`，禁止直接写 `1948.11` 这类小数（会被解析为 1948.11 ≈ 1948.1）。
- `routes.points` 为经纬度，渲染时经 `CHINA_GEO.project` 转为 SVG 坐标；`bases.lonlat` 同理。
- 路线显隐：`year ∈ [from - 0.15, to + 0.45]`；根据地保留前后 ±0.3 年。

### `window.AXIS_COMPARE`

```js
window.AXIS_COMPARE = {
  meta: { source: "…", note: "…" },
  tabs: [
    {
      id: "land", label: "土地纲领", kicker: "耕者有其田？",

```

- 四张表固定 id：`land`、`system`、`works`、`moments`。
- `rows` 每行可以是数组，或 `{ cells }`；单元格可为字符串或 `{ t, tone }`。
- `tone` 取 `yes | partial | no | neutral`，用于“有/部分/无/中性”的视觉标签。
- 校验要求：4 张表、行数 13/6/25/32（`tools/verify_data.js`），行列数一致，`moments` 按年份升序，且含 1925 五卅“大革命高潮”定位。
- 文案口径：教材 + 徐涛强化班复盘笔记；用于辨析，不替代教材原文。
