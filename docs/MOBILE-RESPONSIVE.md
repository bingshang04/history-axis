# 手机 / 平板适配设计

## 目标

在保持桌面 1876×922 视觉不变的前提下，让同一个 `index.html` 在手机与平板上可读、可点、可滚动，不另建移动端页面。

## 断点

- `≥ 1120px`：桌面三栏，保持现状。
- `720–1119px`：平板两栏。左侧考点卡占约 40%，右列上为地图、下为事件卡/图例；时间轴横跨底部。右侧事件区独立滚动。
- `≤ 719px`：手机单列。页面整体纵向滚动，顺序为：地图 → 事件卡 → 考点卡 → 时间轴。`≤900px 且高度≤500px` 的横屏手机也走单列，避免平板两栏被压扁。

## 手机布局

- 顶栏压缩并 `sticky`：大年份约 42px，保留播放/倍速/正放/标签/搜索；隐藏复选框、年份快捷跳转、隐藏边栏与页脚，减少首屏占用。
- 地图固定约 `44vh`，保留缩放按钮和事件气泡；地图内部拖动平移，页面从地图外滑动。
- 事件卡、势力图例、考点关联、考点卡依次排布；考点卡取消内部滚动，随页面自然滚动。
- 时间轴改为横向滑动：画布最小宽度 900px，拖动查看 1840–2025；点击节点仍打开同时间点选择器。自动播放/跳年时自动把播放头滚入可视区。
- 毛中特在手机/平板上切换为**纵向理论节点列表**（按五条主线分组、选中项高亮），避免 SVG 五泳道图谱缩成不可读的小图；桌面仍显示完整图谱。
- 搜索浮层改为手机全宽；toast、时间点选择器限制在视口内。

## 平板布局

- 顶栏压缩为两行；品牌副标题与 meta 精简。
- 两栏 grid：`left stage / left right / timeline timeline`，左卡跨两行；右侧事件与图例在行内滚动。
- 时间轴全宽；保留节点拖拽扫年。

## 触屏交互

- 点按地图 pin / 时间轴节点 / 搜索项均保留原有行为。
- 手机时间轴处于横向滚动模式时，不启用拖拽扫年，避免与原生滑动冲突；桌面/平板仍可拖拽。
- 事件卡的「时间轴」按钮在手机上滚动到时间轴区域。

## 验收

- 尺寸：375×812、390×844、768×1024、1024×768、1024×600、1440×900、1876×922。
- 无横向溢出；地图 34 省 / 95 pin；三 tab、搜索、播放、时间点选择器可用。
- 0 console/page error；桌面布局无回归。

## 阶段图表弹层

- 桌面：`max-width: 1420px` 居中弹层，左侧 5 阶段导航，右侧可滚动内容；`G` 打开、`←/→` 切换、`Esc` 关闭。
- 平板/手机：弹层全屏，`#stageNav` 横向滑动；hero、指标卡、力量对比、事件密度、事件链、重点/易混/清单全部单列。
- 打开时 `body.stage-open` 锁定背景滚动；事件链点击会关闭弹层并定位到地图事件。
